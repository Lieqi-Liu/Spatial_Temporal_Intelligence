# NuScenes Miniset

This folder packages a **question-centric NuScenes miniset** for spatial–temporal driving QA: benchmark tables, qualitative examples with frames, and documentation of how the data was built and evaluated.

## Contents

| Path | Description |
| --- | --- |
| `benchmark_overall.csv` | Per-model MCQ accuracy, random-guess baseline, and FRQ BLEURT |
| `benchmark_per_question.csv` | Per-question-id accuracy (MCQ) or BLEURT (FRQ) for each evaluated model |
| `miniset_example/` | Five randomly sampled scenes with all scene frames, per-question VLM inputs, ground truth, and Qwen3-VL-32B responses (`miniset_examples.json` + `frames/`) |

## Miniset at a Glance

| Stat | Value |
| --- | --- |
| Question IDs | 39 (`SC-*`, `SP-*`, `SU-*`, `TE-*`, `TM-*`, `TRJ-*`) |
| Examples per question ID | 150 |
| Total rows | 5,850 |
| MCQ rows | 4,650 |
| FRQ rows | 1,200 |
| Visual input (most tasks) | 5 consecutive 360° multi-camera grid frames; query object highlighted on frame 5 |
| SC-6 (scene FRQ) | Up to 40 chronological scene grid frames |

The full miniset JSON lives in the development tree at `AutoDriving/Spatial_Temporal_Intelligence/full_nuscenes/questions_with_answers_full_nuscenes_miniset_150_per_id_v4.json`. This folder ships the **evaluation summary** and **inspection examples** only.

## How the Miniset Is Chosen

Selection follows the **NuScenes Miniset V2** design ([`NUSCENES_MINISET_V2_PLAN.md`](../mini_version/NUSCENES_MINISET_V2_PLAN.md)): **question-first**, not group-first.

### Source pool

Candidates are drawn from the fully annotated full-NuScenes task file (originally labeled with Qwen3-VL-30B). Rows with `[ERROR]` model responses are excluded.

### Target size

- **150 examples per question ID** → 39 × 150 = **5,850** rows when all IDs are available.
- At most **12 rows per scene** globally and **1 row per (scene, question ID)** pair, so the miniset spreads across many scenes instead of repeating the same clip.

### Scoring and greedy selection

For each question ID, candidates are ranked with a composite score that balances:

| Signal | Role |
| --- | --- |
| **Scene coverage** | Prefer scenes not yet used (weight 4.0) |
| **Per-task scene diversity** | Avoid over-concentrating one scene within a question ID (weight 2.0) |
| **Hardness prior** | Prefer harder question IDs using `(1 − prior accuracy)` from earlier VLM runs (weight 1.0) |
| **MCQ answer balance** | Prefer ground-truth options that are underrepresented so far (weight 0.75) |
| **Structural MCQ difficulty** | Slight preference for items with more choices (lower random-guess rate; weight 0.25) |
| **Group redundancy penalty** | Discourage reusing the same or nearby `group_id` within a scene |

Selection is **greedy per question ID** with fixed random seed (`7`).

### MCQ choice reindexing

After selection, MCQ answer options may be **permuted** so correct labels (`A`, `B`, …) are more evenly distributed. The semantic correct answer is unchanged; only option order and the stored `ground_truth` letter are updated (`original_ground_truth` / `answer_reindexed` are retained when applicable).

## How Ground Truth Is Generated

Ground truth is **automatically derived** from NuScenes metadata and annotations—not human-written per row.

### Scene-level tasks (`SC-1` … `SC-6`)

Generated by rule-based bootstrapping over each scene’s log, description, and aggregated road-user statistics (`generate_scene_level_gt.py`):

| ID | Format | GT source |
| --- | --- | --- |
| SC-1 | MCQ | Weather / environment classifier on scene description |
| SC-2 | MCQ | Time-of-day from lighting keywords |
| SC-3 | MCQ | Road typology (urban, highway, construction, …) |
| SC-4 | MCQ | Traffic density from average road-user counts |
| SC-5 | MCQ | Scene-level risk heuristic |
| SC-6 | FRQ | Templated natural-language summary of weather, lighting, road type, risk, and notable activity |

### Object / ego tasks (`SP`, `SU`, `TE`, `TM`, `TRJ`)

Built from **5-frame vehicle groups** in `formatted_scenes`:

1. Each scene is split into consecutive 5-frame groups with stitched 2×3 camera grids.
2. Target vehicles are sampled on the 5th frame; bbox-highlighted query images are rendered.
3. `group_*_vehicle_annotations.json` stores frame indices, object tokens, and annotation fields.
4. Task-specific logic maps annotations and ego motion into MCQ options or FRQ reference answers (distance bins, relative bearing, future trajectory class, etc.).

FRQ references are full-sentence descriptions; MCQ labels are discrete classes derived from the same underlying signals.

## Model Benchmark

Four vision-language models were evaluated on the miniset:

- LLaVA 1.5 13B
- Qwen3-VL 8B
- Qwen3-VL 30B-A3B
- Qwen3-VL 32B

**MCQ** is scored by exact option match. The **random-guess baseline** is the mean of `1 / num_choices` over MCQ items (overall ≈ **21.6%**). **FRQ** is scored with **BLEURT** (`Elron/bleurt-base-512`); higher is better. There is no random baseline for FRQ.

### Overall performance

| Model | MCQ accuracy | MCQ baseline | Δ vs baseline | FRQ BLEURT (mean) |
| --- | ---: | ---: | ---: | ---: |
| LLaVA 1.5 13B | 27.6% | 21.6% | +6.0 pp | −0.428 |
| Qwen3-VL 8B | 32.0% | 21.6% | +10.3 pp | −0.220 |
| Qwen3-VL 30B-A3B | 30.8% | 21.6% | +9.2 pp | −0.235 |
| Qwen3-VL 32B | **36.6%** | 21.6% | **+15.0 pp** | −0.288 |

Qwen3-VL 32B leads on MCQ; all models beat the random-guess baseline overall. FRQ remains difficult for every model (mean BLEURT < 0 except on a few trajectory-description items).

## Example Questions

Qualitative examples (5 random scenes, all 39 question types catalogued) are in **`miniset_example/miniset_examples.json`**, with frames under **`miniset_example/frames/`**.

### SC-1 — scene weather (MCQ)

**Question:** What is the primary weather and environmental condition in the current scene?

**Ground truth:** `E` — Rain / Wet road surface

**Qwen3-VL-32B:** `E` ✓

### SC-6 — scene description (FRQ)

**Question:** Describe the overall environment of the scene, including weather, lighting conditions, road type, and notable surrounding activity.

**Ground truth (excerpt):** *The scene takes place during daytime … under rain / wet road surface conditions … moderate traffic …*

**Qwen3-VL-32B (excerpt):** *The scene takes place on a wet, overcast day with heavy rain … reflective, water-covered roads …*

### SP-7 — spatial relation (FRQ)

**Question:** Describe the spatial relationship between the ego vehicle and the object in the red bounding box…

**Ground truth (excerpt):** *The vehicle rear-right at about 28m is located directly to the right of the ego vehicle … moving away …*

**Qwen3-VL-32B (excerpt):** *The object … is a white vehicle parked in a lot to the right … stationary …*

### SU-5 — feasible maneuver (MCQ)

**Question:** Which maneuver is geometrically feasible at this moment?

**Ground truth:** `C` — Maintain lane

**Qwen3-VL-32B:** `C` ✓

### TRJ-2 — ego future maneuver (MCQ)

**Question:** Based on the past 5 consecutive 360-degree multi-camera frames, what is the most likely ego-vehicle maneuver over the next few seconds?

**Ground truth:** `A` — Slightly veer right

**Qwen3-VL-32B:** `B` ✗

Open `miniset_example/miniset_examples.json` for frame paths, choices, and additional metadata per example.

## Question ID Reference

| Family | IDs | Level |
| --- | --- | --- |
| Scene context | SC-1 … SC-6 | Scene |
| Spatial perception | SP-1 … SP-7 | Object |
| Spatial understanding | SU-1 … SU-7 | Object / ego |
| Time extrapolation | TE-1 … TE-6 | Object / ego |
| Time memory | TM-1 … TM-6 | Object / scene |
| Ego trajectory | TRJ-1 … TRJ-7 | Ego |

MCQ IDs end in `-1` … `-5` (or `-6` where applicable); FRQ summary items are `SC-6`, `SP-7`, `SU-7`, `TE-6`, `TM-6`, `TRJ-5`, `TRJ-6`, `TRJ-7`.

## Reproducing Tables and Examples

From the development tree (`AutoDriving/Spatial_Temporal_Intelligence/full_nuscenes/`):

```bash
# Re-run model benchmark (outputs benchmark_summary.json)
python run_miniset_model_benchmark.py

# Export CSV tables from benchmark_summary.json
python -c "..."  # or regenerate via benchmark export script

# Export qualitative miniset examples
python export_miniset_examples.py --seed 42
```

Raw benchmark artifacts: `miniset_model_benchmark_outputs/benchmark_summary.json`, `qwen3_vl_32b_responses.json`.
